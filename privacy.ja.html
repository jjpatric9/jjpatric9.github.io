プライバシーポリシー — Box Stack

2026年10月29日発効

これは英語のプライバシーポリシーの翻訳です。両者の内容が異なる場合は、英語版が優先されます。

Box Stack（以下「本アプリ」）は、カナダ・アルバータ州のJoshua Patrickの事業であるTallman Games（以下「当方」）が開発・配信しています。Joshua Patrickは当方による個人情報の取り扱いに 責任を負い、第11項の連絡先で連絡を受け付けます。本ポリシーでは、本アプリが保存する情報、広告・ アトリビューション・クラッシュレポートの各提供者が収集する情報、およびお客様が選べる内容を説明 します。本ポリシーはAndroid版とiPhone・iPad版の本アプリに適用され、両者が異なる点についても 記載しています。当方のウェブサイトtallman-games.comについては第8項で説明します。

本アプリにはアカウントもログインもなく、当方のサーバーもありません。お客様が作ったもの、獲得 したスコア、解放したものが当方に送信されることはありません。本アプリがネットワークを使うのは、 広告を表示するため、そしてAndroidでは、どの広告キャンペーンがインストールや再訪問につながった かを計測し、クラッシュを報告して修正できるようにするためです。

1. お客様の端末に保存される情報

本アプリは次の情報を端末内に保存し、送信しません。

  • スコア、記録、バッジ、ランドマーク、経験値の合計
  • プレイ回数、ライン数、箱の数、プレイ時間の通算
  • 設定と、チュートリアルを終えたかどうか
  • プレイ中のゲーム
  • 広告の間隔を空けるための、最後に広告を表示した時刻と、その何プレイ前だったか

これらの情報はお客様の身元と結び付いておらず、当方がアクセスする手段もありません。

2. 広告、アトリビューション、クラッシュレポートのために収集される情報

広告はGoogle AdMobが配信します。広告を配信するため、Googleは次の情報を収集・処理します。

  • 端末の広告ID。リセット可能なIDで、氏名、メールアドレス、電話番号は含みません。iPhone・ iPadでは、AppleのApp Tracking Transparencyの確認で本アプリによるトラッキングを許可した場合 にのみ共有されます。許可しない場合も、広告IDなしで広告は表示されます
  • アプリのアクティビティ：広告がリクエストされた、表示された、または操作されたこと
  • 端末とネットワークの情報：リクエストに必然的に伴うもので、IPアドレスを含み、そこから おおよその位置が推定されることがあります
  • 診断情報：起動時間など、本アプリと広告ソフトウェアの動作状況

Googleはこれらの情報について独立した管理者として行動します。その利用は Googleのプライバシーポリシーと Googleのサービスを使用するサイトやアプリから収集した情報のGoogleによる使用 に従います。当方がGoogleから元となるIDや広告プロファイルを受け取ることはありません。

広告は画面下部のバナーと、お客様が自ら選んだときだけ表示される、プレイを続けるための短い広告 です。プレイを中断する広告はありません。

Androidでは、Tenjinが、インストールやその後の起動が広告キャンペーンによるものかどうかを 計測します。そのため、Tenjinのソフトウェアは、広告ID、アプリ固有のインストールID、インストール リファラーとキャンペーンの情報、IPアドレス、端末とOSの情報、言語、ロケールと国、ネットワーク 情報、アプリのバージョン、起動とセッションの時刻を処理することがあります。また、広告キャンペーン が本アプリを楽しんでくれそうな人を見つけられるよう、本アプリの使われ方について次の三つを伝えます。 インストール当日に3回のゲームが終わったこと、セカンドチャンスのために広告を見たこと（見るたびに）、 そして最初の1週間に3回のセカンドチャンスを使ったことです。これらは名前だけで、値は送られません。 スコア、タワー、記録、バッジ、ランドマーク、設定、その他のゲームプレイの情報は受け取りません。

iPhone・iPad版の本アプリにはアトリビューションのソフトウェアは含まれておらず、この段落と次の 段落はiPhone・iPad版には当てはまりません。

Tenjinは当方の委託を受けてこれらの情報を処理し、キャンペーンのアトリビューションを、そのキャン ペーンを担当する広告ネットワーク（AppLovinを含む）に送ることがあります。Tenjinはアメリカ 合衆国の設備を使用しています。その処理はTenjinのプライバシーポリシー に、AppLovinによる情報の利用はAppLovinのプライバシーポリシー に記載されています。

Androidでは、本アプリがクラッシュすると、GoogleのサービスであるFirebase Crashlyticsが レポートを受け取ります。レポートには、エラーのスタックトレース、アプリのバージョン、端末の 機種、OSのバージョンと画面の向き、空きメモリと空きストレージ、端末がroot化されているかどうか、 時刻、そしてインストールID（本アプリ用に作られたランダムなIDで、お客様を特定せず、広告IDでも ありません）が含まれます。Crashlyticsは、クラッシュが起きたセッションと照らし合わせられるよう、 本アプリが起動されたことも記録します。スコア、タワー、記録、バッジ、ランドマーク、設定、その他 のゲームプレイの情報は受け取りません。Googleは Firebaseのデータ処理規約に基づき 当方の委託を受けてこれらの情報を処理し、クラッシュレポートを90日後に削除します。iPhone・iPad版の 本アプリにはクラッシュレポートのソフトウェアは含まれていません。

3. お客様が選べること

  • 同意。 欧州経済領域、イギリス、スイスでは、本アプリは広告をリクエストする前、またTenjinに 接続する前に、GoogleのUser Messaging Platformを通じてお客様の同意を求めます。Tenjinは接続前に 同じ保存済みの同意内容を読み取ります。必要な目的が拒否された場合、Tenjinはオプトアウトし、 アトリビューションのリクエストを行いません。パーソナライズ広告を拒否した場合でも広告は表示される ことがありますが、パーソナライズはされません。Androidでは本アプリのデータを消去する （設定 → アプリ → Box Stack → ストレージとキャッシュ → ストレージを消去）ことで、iPhone・iPadでは本アプリを 削除して再インストールすることで、選択をやり直せます。
  • iPhone・iPadでのトラッキング。 Appleのトラッキングの確認への回答は、 設定 → プライバシーとセキュリティ → トラッキングでいつでも変更できます。
  • 広告ID。 Androidでは、端末の設定 → プライバシー → 広告でリセットまたは削除できます。
  • Googleの広告設定。 パーソナライズはadssettings.google.com で管理できます。
  • 開示または削除。 第11項の連絡先にメールすれば、アトリビューションのデータの開示または削除を 依頼できます。提供者のもとでその依頼を照合するために、広告IDをお尋ねすることがあります。

4. お客様が自ら行う共有

他のアプリに何かを送る操作は二つあり、お客様が使ったときにだけ働きます。スコアカードの共有は その画像を渡し、本アプリの共有はストアのページへのリンクを送ります。受け取るアプリはお客様が 選びます。当方は何も受け取りません。

5. 端末のバックアップ

お客様の端末でAndroidのバックアップが有効になっている場合、記録と設定がお客様自身のGoogle アカウントのバックアップにコピーされ、新しい端末に復元されることがあります。これはお客様の GoogleアカウントのもとでAndroidが行うもので、 Googleのプライバシーポリシーが適用されます。

iPhone・iPadでは、記録と設定は端末自体のバックアップ（iCloudまたはコンピュータ）に含まれ、 新しい端末に復元されることがあります。これはお客様のAppleアカウントのもとでAppleが行うもので、 Appleのプライバシーポリシーが適用されます。

どちらの場合も、プレイ中のゲームと広告のカウンターはバックアップから除外されます。当方がこの データにアクセスすることはできません。

6. お子様

本アプリは13歳未満のお子様を対象としておらず、Google Playの「ファミリー向け」プログラムや App Storeの「キッズ」カテゴリでは配信していません。当方がお子様の情報を故意に収集することは ありません。

7. データの削除

本アプリをアンインストールすると、端末内に保存されたものはすべて消去されます。Androidでは 設定 → アプリ → Box Stack → ストレージとキャッシュ → ストレージを消去でも消去でき、iPhone・iPadでは本アプリを 削除することで消去できます。広告IDは本アプリではなくお客様の端末に属するものです（第3項を参照）。 本アプリのデータ消去やアンインストールでは、すでに広告・アトリビューション・クラッシュレポートの 提供者に送信されたデータは削除されません。クラッシュレポートは90日後に自動的に削除されます。 アトリビューションのデータに関する依頼をTenjinに転送してほしい場合は、第11項の連絡先までご連絡 ください。

8. 当方のウェブサイト

tallman-games.comのウェブサイトは、Cookieを使用せず、アクセス解析や広告を行わず、他社の サーバーから何も読み込みません。

ウェブサイトはGitHub Pagesでホストされています。あらゆるウェブホストと同様に、GitHubは ページを届けサービスを保護するため、お客様のIPアドレスと各リクエストの詳細を受け取ります。 その利用は GitHub General Privacy Statement に記載されています。

カラー投票（tallman-games.com/box-stack/colours）は、ウェブサイトの中で当方に何かを送る唯一の 部分です。投票やパレットの追加をすると、パレットの色、お客様の選択、時刻、そして一人の投票が 一度だけ数えられるようにブラウザが作ったランダムなIDが送られます。名前、アカウント、その他の 文章は収集しません。これらは、投票のサーバーを当方のために運営しているCloudflareに保存 されます。投票が届く速さを制限するため、IPアドレスはそのサーバーのメモリに短時間だけ保持され、 ストレージに書き込まれることはありません。お客様のブラウザが初めて投票するとき、サーバーは、 一つの接続から1日に新しい投票者を少ししか作れないようにするため、IPアドレスと日付から秘密の鍵で 作ったコードも保持します。このコードはお客様のアドレスそのものではなく、1日後に削除されます。 各パレットの得票数は公開されますが、誰が投票したかは公開されません。色を取り出すために開いた 画像はブラウザ内で読み取られ、アップロードや保存はされません。

カラー投票とウェブサイトの他のゲームは、投票と設定をお客様のブラウザ自体のストレージ、つまり お客様の端末にのみ記憶します。ブラウザでこのサイトのデータを消去すると、それらは削除されます。 すでに数えられた投票はお客様と結び付けられません。ご自分の投票の削除を希望する場合は、投票に 使った端末からメールをいただければ、見つけるお手伝いをします。

9. 本ポリシーの変更

今後のバージョンの本アプリがここに記載された以上の情報を収集する場合は、そのバージョンの公開前に 本ポリシーを更新し、上記の発効日を変更します。
